# Reusable Components

A personal and public collection of flexible, customizable, and production-ready reusable components for React applications. This repository is built to save development time and promote consistency across projects by providing well-tested UI and logic building blocks.

## Features

-  **Highly Customizable**: Designed for maximum flexibility with easily overridable styles and adaptable props.
-  **Production-Ready**: Built and refined through real-world project usage with performance and accessibility in mind.
-  **Composable**: Easy to mix, match, and compose components to fit different UI needs.
-  **Modern React Patterns**: Built using functional components and React hooks.
-  **Personal & Public Usage**: Maintained for personal development while being openly available for public use and learning.

## Usage

Directly copy and paste components from this repository into your React application or import them locally after cloning the repository.

This repository is **not published as an npm package**. Components are intended for direct usage and customization.

## Available Components

- **Button**: Primary, custom, animated, and utility buttons
- **Toggle Button**
- **Modal / Drawer / Dialog**
- **Input**: Text, password, textarea, search
- **Checkbox & Radio**
- **Dropdown & Select**
- **Tabs**
- **Tooltip**
- **Spinner & Loader**
- **Card**: Team cards, pricing cards, content cards
- **Alert / Notification**
- **Pricing Sections**
- **Infinite Scrollers & Marquees**
- **Background Effects (Gradients, Masks, Blur)**
- **...and more**

## Customization

All components offer props for adjusting styling and behavior.  
For advanced customization, use the `className` or `style` props or wrap components with your own logic.
